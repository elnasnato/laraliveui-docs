# Calendar & Date Picker

Komponen kalender dan date picker.

## Calendar

```blade
<laraliveui:calendar />
```

## Date Picker

```blade
<laraliveui:date-picker name="tanggal" />
<laraliveui:date-picker name="range" mode="range" />
```

## Time Picker

```blade
<laraliveui:time-picker name="waktu" />
```

## Referensi

### `laraliveui:date-picker`

| Prop | Deskripsi |
|------|-----------|
| `name` | Nama field |
| `mode` | Mode: `single`, `range` |
