# Slider

Slider range untuk memilih nilai dalam rentang.

```blade
<laraliveui:slider name="range" min="0" max="100" step="1" />
<laraliveui:slider name="harga" min="0" max="10000000" step="100000" />
```

## Referensi

### `laraliveui:slider`

| Prop | Deskripsi |
|------|-----------|
| `name` | Nama field |
| `min` | Nilai minimum |
| `max` | Nilai maksimum |
| `step` | Langkah kenaikan |
