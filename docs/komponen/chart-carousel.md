# Chart & Carousel

Komponen chart dan carousel.

## Chart

```blade
<laraliveui:chart name="penjualan" :data="$chartData" />
```

Chart menggunakan library ringan tanpa dependensi eksternal.

## Carousel

```blade
<laraliveui:carousel>
    <div>Slide 1</div>
    <div>Slide 2</div>
    <div>Slide 3</div>
</laraliveui:carousel>
```
