# Pillbox

Komponen untuk menampilkan tag/pill yang dapat dihapus.

```blade
<laraliveui:pillbox name="tags" :value="['laravel', 'livewire', 'tailwind']" />
```

## Referensi

### `laraliveui:pillbox`

| Prop | Deskripsi |
|------|-----------|
| `name` | Nama field |
| `value` | Array nilai default |
