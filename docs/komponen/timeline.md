# Timeline

Menampilkan urutan kejadian secara kronologis.

```blade
<laraliveui:timeline>
    <laraliveui:timeline.item title="Pendaftaran" date="2024-01-01">
        User mendaftar akun
    </laraliveui:timeline.item>
    <laraliveui:timeline.item title="Verifikasi" date="2024-01-02">
        Email diverifikasi
    </laraliveui:timeline.item>
    <laraliveui:timeline.item title="Aktif" date="2024-01-03">
        Akun diaktifkan
    </laraliveui:timeline.item>
</laraliveui:timeline>
```

## Referensi

### `laraliveui:timeline.item`

| Prop | Deskripsi |
|------|-----------|
| `title` | Judul item |
| `date` | Tanggal item |
