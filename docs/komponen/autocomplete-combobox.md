# Autocomplete, Combobox

Komponen input dengan saran otomatis.

## Autocomplete

```blade
<laraliveui:autocomplete name="negara" :options="$negara" />
```

## Combobox

```blade
<laraliveui:combobox name="user" :options="$users" />
```

## Referensi

### `laraliveui:autocomplete`

| Prop | Deskripsi |
|------|-----------|
| `name` | Nama field |
| `options` | Array/Collection opsi |

### `laraliveui:combobox`

| Prop | Deskripsi |
|------|-----------|
| `name` | Nama field |
| `options` | Array/Collection opsi |
