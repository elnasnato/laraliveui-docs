# Color Picker

Pemilih warna.

```blade
<laraliveui:color-picker name="warna" />
<laraliveui:color-picker name="bg-color" value="#6366f1" />
```

## Referensi

### `laraliveui:color-picker`

| Prop | Deskripsi |
|------|-----------|
| `name` | Nama field |
| `value` | Nilai default |
