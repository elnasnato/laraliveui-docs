# Separator

Garis pemisah vertikal atau horizontal.

```blade
<laraliveui:separator />
<laraliveui:separator text="Atau" />
```

## Orientasi

```blade
<laraliveui:separator orientation="horizontal" />
<laraliveui:separator vertical />
```

## Variant

```blade
<laraliveui:separator variant="subtle" />
```

## Referensi

### `laraliveui:separator`

| Prop | Deskripsi | Default |
|------|-----------|---------|
| `orientation` | Orientasi: `horizontal`, `vertical` | `horizontal` |
| `vertical` | Shortcut untuk orientasi vertikal | `false` |
| `variant` | Varian: `subtle` | `null` |
| `text` | Teks di tengah separator | `null` |
| `faint` | Tampilan lebih redup | `false` |
