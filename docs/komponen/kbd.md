# KBD

Komponen untuk menampilkan tombol keyboard.

```blade
<laraliveui:kbd>⌘K</laraliveui:kbd>
```

## Ukuran

```blade
<laraliveui:kbd size="xs">⌘K</laraliveui:kbd>
<laraliveui:kbd size="sm">⌘K</laraliveui:kbd>
<laraliveui:kbd>⌘K</laraliveui:kbd>
<laraliveui:kbd size="lg">⌘K</laraliveui:kbd>
```

## Kombinasi Tombol

```blade
<laraliveui:kbd>Ctrl + C</laraliveui:kbd>
```

## Referensi

### `laraliveui:kbd`

| Prop | Deskripsi | Default |
|------|-----------|---------|
| `size` | Ukuran: `xs`, `sm`, `md`, `lg` | `md` |
| `separator` |Pemisah antar tombol | `+` |
