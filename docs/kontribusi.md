# Kontribusi

LaraLiveUI adalah proyek open-source (MIT) dan kontribusi sangat diterima!

## Cara Berkontribusi

1. **Fork** repositori di GitHub
2. **Clone** fork Anda
3. Buat **branch** fitur: `git checkout -b fitur-keren`
4. **Commit** perubahan: `git commit -m 'feat: tambah fitur keren'`
5. **Push** ke branch: `git push origin fitur-keren`
6. Buat **Pull Request**

## Repositori

- **laraliveui**: [github.com/elnasnato/laraliveui](https://github.com/elnasnato/laraliveui)
- **laraliveui-starter-kit**: [github.com/elnasnato/laraliveui-starter-kit](https://github.com/elnasnato/laraliveui-starter-kit)
- **laraliveui-docs**: [github.com/elnasnato/laraliveui-docs](https://github.com/elnasnato/laraliveui-docs)

## Pedoman

- Ikuti PSR-12 untuk PHP
- Gunakan conventional commits (`feat:`, `fix:`, `docs:`, dll)
- Tambahkan test untuk fitur baru
- Dokumentasikan perubahan di README
