# LaraLiveUI Docs

Dokumentasi resmi [LaraLiveUI](https://github.com/elnasnato/laraliveui) — UI component library untuk Livewire + Tailwind CSS.

Dibangun dengan [Docusaurus](https://docusaurus.io/), di-deploy otomatis ke GitHub Pages.

## Memulai

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

## Deploy

Push ke `main` → GitHub Actions build & deploy otomatis ke GitHub Pages.
